Privacy policy

Elio has no telemetry. This page lists the few times it talks to anything other than the servers you told it to connect to, and what it says.

The short version

  • No telemetry, no analytics, no crash reports, no advertising and no account of its own.
  • Your servers, passwords, keys, snippets and settings stay on your device. Passwords and keys are never written to logs.
  • Nothing leaves your device except what is listed under When Elio uses the network. Most of it happens only if you turn a feature on.

What stays on your device

Elio keeps its settings, your server library, snippets, identities, known host keys, workspaces and command history in its data folder: %LOCALAPPDATA%\Elio on Windows, the usual application folder on macOS and Linux, a folder of its own on a phone, or the folder named data beside the program in portable mode. Saved passwords and passphrases are in a vault encrypted with a key that the operating system holds.

Command suggestions are worked out on your device from commands you ran before and from the shell's history file. They are not sent anywhere.

When Elio uses the network

  • The servers you connect to. SSH, SFTP, Telnet and Mosh servers, serial ports, jump hosts and proxies are the ones you added. They receive what you type and what you transfer, as with any terminal.
  • The version check (computers only). At most once a day Elio asks GitHub's API for the latest release of localtonet/elio and tells you if there is a newer one. Nothing about you or your servers is sent beyond the request itself, which GitHub sees as it sees any other, including your network address (see GitHub's privacy statement). Check for new versions when Elio starts in Settings turns it off. Phones do not make this request.
  • Sync (only if you turn it on). Everything is encrypted on your device with a key made from your password before it leaves, so the sync server, sync.elio.sh by default or one of your own, stores ciphertext only. It cannot read it. Like any server it receives the network address of each request, which it uses to limit abuse, and it holds the sync code, or the Localtonet account, that says whose data it is, together with the size and time of what is stored. The server is open source and can be run by you.
  • Shared terminals (only if you share one). The stream is encrypted from end to end with a key made from the password you give the viewer. The relay, the same sync server unless you chose another in Settings, passes on bytes it cannot read, and sharing ends when you stop it.
  • Localtonet (only if you sign in). Signing in lists your Localtonet devices and lets Elio connect to them. What Localtonet receives and keeps is governed by Localtonet's own terms and privacy policy at localtonet.com. The key Elio is given can only list devices and prove your identity to the sync server.
  • Importing from DigitalOcean or AWS (only when you run it). The token or access key you type goes to that provider only. It is kept only if you tick Remember in the vault.
  • Links and plugins. A web address you Ctrl+click opens in your browser. A plugin is a program you installed yourself and runs under its own rules; Elio never gives plugins passwords or keys.
  • AI tools (only if you allow them). A tool started with elio --mcp sees the names and addresses of your servers, never passwords or keys, and can run commands only where you allowed it twice. What runs is written to mcp-commands.log and mcp-activity.jsonl in the data folder on your device.

On a phone

Elio asks for the camera only to read the QR code that adds the device to sync, and keeps no picture. The app lock uses the device's own fingerprint, face or passcode check; Elio never receives that data. On Android Elio holds the permissions for internet access and the camera. On iOS it asks to use the local network so that it can reach servers on your own network.

This website

elio.sh is a handful of static files with no cookies, no analytics and no requests to other sites. Like any web server, the host of elio.sh receives the network address and browser details of each request. Downloads are served by GitHub, under its privacy statement.

Your choices

  • Turn off the version check, sync, sharing, Localtonet sign-in and AI tools in Settings. Each one is off until you use it, except the version check.
  • Delete Elio's data folder to remove everything it keeps on your device.
  • Run your own sync server if you would rather not use sync.elio.sh.

Questions and changes

Ask on the issue tracker. Security problems go through the private route in SECURITY.md. When this policy changes, the change is visible in the repository's history.
